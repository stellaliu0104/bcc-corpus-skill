# 研究问题 → BCC 检索式 对照示例库

> 用法：把用户的问题与下表"问题类型"对照，**优先照搬同型例子的检索式**，替换其中的词/词性即可。找不到同型再参考 `bcc_syntax.md` 自行组合。

## 1. 频率与搭配类（→ freq）

| 用户问题（同型） | 检索式 | 说明 |
|---|---|---|
| "'的'前面的形容词都有哪些？最高频的是什么？" | `a的n` | 形容词+的+名词 |
| "'很'后面都接哪些词？" | `很d` | 很+副词 |
| "'很'后面接哪些形容词？" | `很a` | |
| "'把'字句里'把'后面接什么名词？" | `把n*v` | 把+名词+动词 |
| "'们'前面的名词有哪些？" | `n们` | |
| "双音节形容词+的+名词有哪些？" | `(a)的n{len($1)=2}` | 长度条件 |
| "以'化'结尾的词有哪些？" | `v{end($1)=[化]}` | 注意 $1 指括号里的成分 |
| "'被'字开头的介词结构搭配" | `被n*v` | |

## 2. 对比类（→ compare 子命令，或分别 freq）

| 用户问题（同型） | 检索式A / 检索式B |
|---|---|
| "'很'和'非常'的搭配有什么差别？" | `很a` vs `非常a` |
| "'经常'和'常常'用法一样吗？" | `经常d` vs `常常d`（或直接 `经常` vs `常常` 看 freq） |
| "'曾经'和'已经'怎么分工？" | `曾经d` vs `已经d` |
| "'二'和'两'的使用差别？" | `二m` vs `两m` |
| "'二'和'两'跟量词搭配有什么区别？" | `二m` vs `两m` |
| "名词前用'的'还是'地'？" | `a的n` vs `a地v` |

**对比类判断标志**：问题里出现"和/与/跟…（的）差别/区别/对比/分工/一样吗/哪个更"。

## 3. 语境例句类（→ context）

| 用户问题（同型） | 检索式 |
|---|---|
| "给我一些'居然'的用例" | `居然` |
| "'洗'和'澡'隔开的例子（洗个澡/洗了澡）" | `洗*澡` |
| "'如果…就'的句子" | `如果*就` |
| "'很'后接心理动词的例子" | `很(~){$1=[喜欢 担心 害怕 后悔 失望 高兴 悲伤 愤怒]}` |
| "'们'前面的代词例子" | `r们` |

## 4. 词表条件类（查"某一类词"时优先用）

| 用户问题（同型） | 检索式 |
|---|---|
| "'很'能修饰哪些频率副词？" | `很(~){$1=[经常 常常 偶尔 时常 往往 屡屡]}` |
| "程度副词+'的'+名词 的例子" | `(~){$1=[很 非常 挺 太 十分 越来越]}的n` |
| "'太'+心理动词" | `太(~){$1=[喜欢 担心 害怕 后悔 失望]}` |

**为什么要用词表**：词性标注无法区分语义小类（如 v 分不出心理动词/情态动词），问"某类词"时必须用 `{$1=[...]}` 词表列举。

**常用词性速记（易错）**：数词用 `m`（二/两/几/三），量词用 `q`（个/次/遍/趟），助词"的"是 `uj`。如"二"和"两"的搭配对比 → `二m` vs `两m`。

## 5. 通配符选择（最容易错，务必自查）

| 需求 | 用 | 千万别用 |
|---|---|---|
| 中间隔任意多个词（不跨标点） | `*` → `如果*就` | `~` 只匹配**恰好一个**词 |
| 中间隔可跨标点 | `^` → `吃^水果` | |
| 隔恰好一个词 | `~` → `很~` | |
| 隔恰好 N 个**字** | `.` → `洗..澡`（两个字） | |

## 6. 高级条件（低频使用）

| 需求 | 检索式 |
|---|---|
| 同词重复（"V一V"式） | `(v)一(v){$1=$2}` |
| 排除法：'的'前形容词但排除'好/新' | `(a)的{$1!=[好 新]}` |
| 组合过滤：A 结果里再查 B | `查询A AND 查询B`（如 `很a AND 很不a`） |
| 排除：A 但不要 B | `查询A NOT 查询B` |

## 7. 基于语言学概念的检索式映射（linguistics_kb.md 支撑）

> 用户用《黄廖本》/《叶徐本》概念提问时，对照本节翻译；概念定义来源见 `references/linguistics_kb.md`。

### 7.1 词类 → jieba 词性标签

| 用户说的语言学概念 | jieba 词性 | 检索式示例 | 说明 |
|---|---|---|---|
| 名词 | `n`（普通）/ `nr`（人名）/ `ns`（地名）/ `nt`（机构）/ `nz`（其他专名） | `n们` | 集合名词/专有名词注意区分 |
| 动词（一般） | `v` | `v了` | 含动作、存在、变化等 |
| 心理活动动词 | 无专属标签，用词表 | `很(~){$1=[喜欢 担心 害怕 羡慕 讨厌 希望 后悔 失望 高兴 愤怒 紧张 期待]}` | v 无法区分语义小类 |
| 能愿动词（助动词） | `v` 或 `vd`，**无专属标签** | `(~){$1=[能 会 能够 可以 应该 应当 要 敢 肯 愿意]}v` | 必须用词表，不能只写 `v` |
| 趋向动词 | `v`，无专属标签 | `v(~){$1=[来 去 上 下 进 出 回 开 过 起 上来 下去 起来]}` | |
| 形容词（性质） | `a` | `很a` | |
| 形容词（状态） | `b` 或 `a`（jieba 有时混标） | `(~){$1=[雪白 笔直 绿油油 水灵灵]}` | 状态形容词建议用词表 |
| 区别词 | `b`（jieba） | `b的n` | 如"男的、女的、大型的" |
| 数词 | `m` | `两m` | "二/两/几/三"均标 `m` |
| 量词（名量词） | `q` | `nq` | 如"个/只/条/张" |
| 量词（动量词） | `q` | `v了mq` | 如"看了三次" |
| 副词（程度） | `d` | `d的a` | 细分见下方 |
| 副词（频率） | `d`，无专属标签 | `(~){$1=[经常 常常 时常 往往 偶尔 屡次 总是 始终]}d` | 必须用词表 |
| 副词（时间） | `d`（jieba 对部分时间副词标 `t`） | `(~){$1=[已经 曾经 刚 正在 将要 马上 立刻]}` | |
| 副词（语气） | `d`，无专属标签 | `(~){$1=[居然 竟然 果然 简直 难道 偏偏 索性 明明 恰恰]}` | |
| 代词（人称） | `r` | `r们` | 我/你/他/她/它/我们等 |
| 代词（疑问） | `r` | `(~){$1=[谁 什么 哪 多少 怎么]}` | |
| 介词 | `p` | `p n v` | 如"把/被/对/从/在" |
| 连词 | `c` | `c` | 如"和/但是/如果/虽然" |
| 助词（结构助词"的地得"） | `uj`（的）/ `ud`（得）/ `uv`（地） | `a uj n` | "的"字是 uj，非常重要 |
| 助词（动态助词） | `ul`（了）/ `uz`（着）/ `ug`（过） | `v ul` | |
| 语气词 | `y` | `v y` | 了/吗/呢/吧/啊等句末 |

### 7.2 句式 → 检索式

| 句式（语言学名称） | 核心结构 | 检索式 | 说明 |
|---|---|---|---|
| 把字句 | "把/将"+名词+动词（+补语） | `把n*v` | 必须用 `*`，中间可能有状语 |
| 被字句 | "被/给/叫/让"+（名词）+动词 | `被n*v` 或 `被v` | 无名词的短被动用 `被v` |
| 兼语句 | 动词₁+名词（兼语）+动词₂ | `v n v` | 如"请他来"；可进一步限定 v 词表 |
| 连谓句 | 动词₁+动词₂（无停顿，无连词） | `v v` | 如"进来坐下" |
| 存现句 | 处所+存在动词+名词 | `ns(~){$1=[有 是 住 坐]}n` | 处所词+存在变化消失动词+人/物 |
| 双宾句 | 动词+（指人）宾语+（指物）宾语 | `(~){$1=[给 送 告诉 教]}nr n` | 动词用词表列举 |
| V一V（尝试义重叠） | 同一动词重叠 | `(v)一(v){$1=$2}` | 看一看、想一想 |
| "是…的"强调句 | 是+（状语/处所/时间）+v+的 | `是*v的` | 强调动作发生的时间/处所/方式 |

### 7.3 句法成分 → 检索式思路

| 句法成分 | 检索思路 | 典型检索式 |
|---|---|---|
| 定语（名词修饰） | 修饰语+的+中心名词 | `a的n` / `n的n` |
| 状语（副词/介词短语修饰） | 修饰成分+动词/形容词 | `d a` / `p n v` |
| 补语（程度补语） | 动词/形容词+得+补充成分 | `v ud (a)` |
| 宾语（谓宾/名宾） | 动词+名词/动词 | `v n` / `v v` |

### 7.4 短语类型 → 检索式

| 短语类型 | 检索式示例 | 说明 |
|---|---|---|
| 偏正短语（定中） | `a的n` | 形容词定语+名词 |
| 偏正短语（状中） | `d v` | 副词状语+动词 |
| 中补短语 | `v ud a` | 动词+得+形容词（如"跑得快"）|
| "的"字短语 | `a uj` | 形容词+的（指称用法，如"好的""大的"）|
| 介词短语 | `p n` | 介词+名词（如"在北京""对我"）|

## 8. 翻译自查清单（输出检索式前逐条核对）

1. 跨词通配是否用了 `*`（而不是 `~`）？
2. 问题是否是对比类？是 → 用 compare（两条检索式）
3. 词性（v/a/d…）能表达"这一类词"吗？不能 → 改用 `{$1=[词表]}`
4. 括号 `()` 包住的对象和条件里的 `$1` 是否对应？
5. 用户问"多少/频率" → freq 或 count；问"什么样子/例句" → context
